# Routine Week

Routines with a rhythm, a todo list for today, and a Monday–Sunday week overview where you
can plan which routines (and other todos) land on which day. See [AGENTS.md](./AGENTS.md)
for the concept and [CLAUDE.md](./CLAUDE.md) for the tech stack and project rules.

## Get started

```bash
npm run web      # expo start --web
npm start        # expo start (choose iOS/Android/web from the menu)
```

```bash
npm run check     # eslint + tsc
npm test          # jest
```

No backend — everything persists locally via AsyncStorage.
